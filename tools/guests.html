K & M / RUANG PENGELOLA

Setiap tamu, undangan istimewa.

Kelola nama, jumlah tamu, dan tautan undangan di perangkat Anda. Halaman ini tidak diunggah oleh alur GitHub Pages.

Cara menggunakan
  1. Buka data/guests.csv melalui tombol di bawah. Sudah ada 800 tamu contoh.
  2. Ganti nama tamu. Token tetap sama agar tautan yang dibagikan tidak berubah.
  3. Masukkan alamat situs GitHub Pages, lalu salin tautan per tamu atau ekspor semua tautan.
  4. Klik Unduh daftar tamu, simpan menggantikan data/guests.csv.
  5. Jalankan python scripts/build.py, lalu unggah ulang folder public.

Gunakan alamat lokal saat mencoba. Ganti dengan URL GitHub Pages sebelum membagikan undangan.
